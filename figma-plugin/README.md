# Plugin source

See the [project README](../README.md), [installation guide](../docs/installation.md), [validation results](../docs/validation.md), and [permission findings](../docs/connection-permissions.md).

The Figma sandbox entry is src/code.ts. The localhost panel entry is src/ui.ts. Build output code.js and ui.js are generated by npm run build. bootstrap.html forwards messages between the opaque Figma iframe and its own localhost child, with exact source and origin checks.

Link state version 2 is stored in chunked plugin-private document data and isolated by target Pie. Approved grants are kept only in the user's local clientStorage. Compatible updates preserve native IDs; type replacements rebuild the affected subtree. Legacy links require an explicit Import as new.
