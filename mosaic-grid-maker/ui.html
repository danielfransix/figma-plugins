Sort options guide
As selected

Places layers in the order you selected them. First selected goes top-left.

Width (small/large first)

Sorts layers by width before placing. Small first tends to create tighter packing; large first gives a heavier top.

Height (small/large first)

Sorts by height. Small first keeps columns even; large first creates a cascading effect.

Area (small/large first)

Sorts by total area (width x height). Large first places dominant items first for balanced distribution.
